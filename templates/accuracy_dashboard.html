How the learning engine works
  1. Outcome collection — when the scraper detects a completed live match, the final score is saved automatically. Any prediction made for that match (via the live-match dropdown) is instantly backfilled with the real score. You can also add outcomes manually using the override form above.
  2. Error analysis — after each new outcome, the engine computes the difference between what was predicted and what actually happened, grouped by venue and by match phase (based on how many overs remained when the prediction was made).
  3. Adjustment learning — adjustments are blended using an Exponential Moving Average (α = 0.3), so recent matches carry more weight than old ones. A minimum of 5 samples is required before an adjustment is applied to live predictions.
  4. Application — venue offsets are added to the projected final score; phase multipliers scale the remaining-runs projection up or down. Both are capped (±25 runs / ±15%) to prevent runaway corrections from small samples.
